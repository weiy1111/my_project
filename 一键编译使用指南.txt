============================================
   图片批量替换工具 - 一键编译使用指南
============================================

🎯 一键编译功能介绍：
------------------------
一键编译脚本让您只需选择一张图片，就能自动生成带有该图片作为图标的可执行文件！

📁 相关文件：
-------------
• one_click_build.py     - 一键编译Python脚本
• 一键编译.bat           - 一键编译批处理文件（推荐）

🚀 使用方法：
-------------

方法1：双击运行批处理文件（最简单）
----------------------------------
1. 双击 "一键编译.bat" 文件
2. 在弹出的文件选择对话框中选择一张图片
3. 等待编译完成
4. 自动生成发布包

方法2：运行Python脚本
--------------------
1. 打开命令行
2. 运行: python one_click_build.py
3. 在弹出的文件选择对话框中选择一张图片
4. 等待编译完成

✨ 脚本会自动完成以下工作：
--------------------------
1. ✅ 检查并安装必要的依赖
2. ✅ 让您选择图片文件
3. ✅ 自动将图片转换为ICO图标格式
4. ✅ 使用该图标编译可执行文件
5. ✅ 创建完整的发布包
6. ✅ 清理临时文件

📦 生成的文件：
---------------
• dist/image_replacer.exe          - 主程序
• 发布包/image_replacer.exe        - 发布版本
• 发布包/run_image_replacer.bat    - 启动脚本
• 发布包/README.txt               - 使用说明
• 发布包/使用说明.txt             - 详细指南

🎨 支持的图片格式：
------------------
• PNG (*.png)
• JPEG (*.jpg, *.jpeg)
• BMP (*.bmp)
• GIF (*.gif)

💡 图标建议：
-------------
• 尺寸: 256x256 像素（最佳）
• 格式: 正方形图片
• 质量: 建议小于100KB

⚠️ 注意事项：
-------------
1. 确保Python环境正常
2. 首次运行会自动安装必要的依赖
3. 编译过程需要几分钟时间
4. 确保有足够的磁盘空间

🔧 故障排除：
-------------
如果编译失败：
1. 检查Python是否正确安装
2. 确保网络连接正常（用于下载依赖）
3. 重启命令行窗口再试

🎉 成功标志：
-------------
编译成功后，您会看到：
• 控制台显示 "🎉 一键编译完成！"
• 弹出成功提示对话框
• 发布包目录包含所有必要文件
