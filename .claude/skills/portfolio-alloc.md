# 配仓策略推荐

根据 TRADING_SYSTEM.md 的规则，分析当前市场并推荐具体配仓方案。

## 执行步骤

### 1. 读取交易系统规则

读取项目根目录的 `TRADING_SYSTEM.md`，严格按照其中的仓位管理、买入信号、止损规则执行。

### 2. 获取市场数据

使用项目代码获取以下数据：

```python
import sys
sys.path.insert(0, '.')
from data.realtime import get_realtime_quotes, get_recent_klines
from discovery.tech_analysis import build_tech_analysis
from discovery.fund_flow import get_fund_flow_rank
from discovery.scorer import discover_stocks, DiscoveryFilters
```

#### ETF 分析 (40% 底仓)

对以下 4 只 ETF 分别获取技术分析数据：

| ETF | 代码 | 仓位上限 |
|-----|------|----------|
| 创业板ETF | 159915 | 10% |
| 科创50ETF | 588000 | 10% |
| AI人工智能ETF | 159819 | 10% |
| 芯片ETF | 159995 | 10% |

对每只 ETF 分析：
- 当前价格、涨跌幅
- 均线排列 (多头/空头/纠缠)
- MA20 乖离率
- 距 MA10/MA20 支撑距离
- 资金流向 (今日/3日/5日)
- 是否触发买入信号 A (回踩支撑)
- 是否触发止损信号 (跌破 MA20)

#### 个股筛选 (30% 机动仓)

使用 `discover_stocks()` 筛选候选股，条件：
- 评分 > 45
- 主力净流入
- 均线多头排列
- 无双头确认风险
- MA20 乖离 < 15%

对 Top 候选做技术分析，检查是否符合买入信号 A/B/C。

### 4. 强制规则检查

输出前必须检查以下规则，任何一条不满足都要在风险提示中标红：

- [ ] 总仓位 ≤ 70%
- [ ] 单只个股 ≤ 15%
- [ ] 现金 ≥ 30%
- [ ] 每只个股有明确止损位
- [ ] 没有追涨买入 (涨幅 > 5% 的不追)
- [ ] 没有双头确认的股票
- [ ] MA20 乖离 > 20% 的不买
- [ ] 连续亏损 3 笔时提示停止交易

### 5. 注意事项

- ETF 使用 akshare 获取数据 (`fund_etf_hist_em`)，因为部分 SH ETF 无法通过新浪 API 获取
- 科创50 ETF (588000) 需要用 akshare 获取
- 如果某只 ETF 无法获取数据，跳过并说明
- 个股推荐必须附带完整的止损位和目标位
- 不推荐当日涨幅 > 5% 的个股 (追涨禁止)
- 不推荐 MA20 乖离 > 20% 的标的 (乖离过高禁止)
