# 股票发现系统使用文档

本文档面向日常使用者，说明如何启动系统、查看候选股票、分析板块、使用 LLM、保存推荐和复盘。

> 本系统用于辅助研究股票和板块强弱，不构成投资建议。实际交易请结合个人风险承受能力和账户规则。

## 1. 启动系统

在项目目录运行：

```powershell
conda activate pro
cd quant_trading
python scripts/run_dashboard.py --host 127.0.0.1 --port 8088
```

如果没有激活 `pro` 环境，可能遇到 Flask/click 版本不兼容。安装和排错见 [安装与环境文档](INSTALL.md)。

本机浏览器打开：

```text
http://localhost:8088
```

如果要让同一局域网同事访问：

```powershell
python scripts/run_dashboard.py --host 0.0.0.0 --port 8088
```

同事访问：

```text
http://你的局域网IP:8088
```

如果你的局域网 IP 是 `10.234.57.81`，访问地址为：

```text
http://10.234.57.81:8088
```

如果端口被占用，可以先关闭旧服务或换端口：

Windows 11:

```powershell
netstat -ano | findstr :8088
taskkill /PID <PID> /F
python scripts/run_dashboard.py --host 0.0.0.0 --port 8090
```

Linux/macOS:

```bash
lsof -i :8088
kill <PID>
python scripts/run_dashboard.py --host 0.0.0.0 --port 8090
```

## 2. 推荐的每日使用流程

### 2.1 盘前或开盘后

预热缓存，减少页面等待时间：

```bash
python scripts/update_discovery_cache.py --period 即时 --limit 100 --details 40
```

打开首页：

```text
http://localhost:8088
```

重点看：

- 今日主力资金是否明显流入。
- 候选股票是否集中在少数大科技子板块。
- 明日建仓分是否高。
- 是否提示“等待回踩”或“可试仓”。

### 2.2 盘中

首页适合做快速筛选：

- 按综合评分看整体强度。
- 按明日建仓看低吸和建仓候选。
- 按资金持续看近几日资金是否连续。
- 按回踩机会看是否接近可观察区间。

不要只看单个分数。优先找同时满足以下条件的股票：

- 主力资金为正。
- 近 3 日或近 30 日资金不弱。
- 涨幅没有过热。
- 消息面没有明显负面事件。
- 所属板块也处于强势或偏强。

如果目标是“宁可漏掉，也不要误检坏股票”，建议使用严选模式。严选模式会优先剔除当日资金流出、近 3 日或近 30 日资金不为正、跌破 MA20、RSI 过热、风险分偏高、趋势偏弱、数据质量偏低、消息面偏负面、明日建仓分不足的股票。

### 2.3 收盘后

保存当天推荐：

```bash
python scripts/save_daily_recommendations.py --sort-by tomorrow --limit 20
```

复盘历史推荐：

```bash
python scripts/review_recommendations.py
```

A 股当日 K 线和资金流数据通常在收盘后逐步稳定。建议 15:30 之后再拉取当天数据；如果仍然没有当天数据，可以 16:00 后重试。

## 3. 页面说明

### 3.1 首页 `/`

首页用于快速发现候选股票。

常用控件：

- `周期`：即时、3 日、5 日、10 日资金流周期。
- `排序`：综合评分、明日建仓、资金持续、回踩机会。
- `最低分`：过滤低质量候选。
- `普通模式/严选模式`：严选模式会牺牲召回率，优先降低误检率。
- `保存今日推荐`：把当前候选写入 SQLite，供后续复盘。

核心字段：

| 字段 | 说明 |
|---|---|
| 综合评分 | 资金、趋势、量能、风险、消息等综合结果 |
| 明日建仓分 | 更偏向短期建仓时机的评分 |
| 今日资金 | 当日主力净流入或净流出 |
| 3 日资金 | 近 3 日资金持续性 |
| 30 日资金 | 中期资金方向 |
| 严选 | 是否通过低误检硬过滤 |
| 触发状态 | 可试仓、等待回踩、资金转弱等 |

操作：

- 单击股票行：查看右侧概要。
- 双击股票行：进入二级详情页。
- 加入观察池：后续在 `/watchlist` 跟踪。

### 3.2 个股详情 `/stock/<code>`

二级页用于研究单只股票。

重点看：

- 近 30 日资金流入流出。
- 近 30 日涨跌幅统计，包括日涨跌幅和区间累计涨跌。
- 今日资金结构：超大单、大单、中单、小单。
- 买入区间、触发条件和止损参考。
- 近期消息面事件。
- LLM 分析结果和历史分析记录。

建议使用方式：

1. 先看资金是否连续改善。
2. 再看价格是否已经大幅拉升。
3. 查看消息面是否有负面事件。
4. 最后用 LLM 分析做辅助总结。

资金结构判断：

- `大单吸筹`：超大单/大单流入，小单流出，偏向资金承接。
- `资金共振`：大单和小单同时流入，热度较高，但涨幅大时要防追高。
- `散户接盘风险`：大单流出，小单流入，严选模式会优先回避。
- `资金撤退`：大单和小单同时流出，等待重新转强。

### 3.3 板块页 `/sectors`

板块页用于判断大科技内部哪个方向更强，也适合辅助基金或 ETF 方向选择。

页面包含：

- 板块热度。
- 今日资金、近 3 日资金、近 30 日资金。
- 上涨家数和下跌家数。
- 短期适合度。
- 长期适合度。
- ETF 动作建议。
- 板块强势股票。

ETF 动作含义：

| 动作 | 含义 |
|---|---|
| 可分批建仓 | 短期和长期条件都较好，可考虑分批观察 |
| 短线试仓 | 短期资金和热度较强，但长期确认可能不足 |
| 适合定投观察 | 长期资金方向较好，适合跟踪或分批低吸 |
| 等待回踩 | 方向不差，但当前位置或资金节奏不适合追 |
| 暂不优先 | 热度或资金不足，不作为当前重点 |

使用建议：

- 买 ETF 或基金时优先看长期适合度。
- 做短线主题时优先看短期适合度。
- 如果短期分高但涨幅过大，要避免追高。
- 如果长期分高但短期分一般，更适合观察回踩或定投。

### 3.4 观察池 `/watchlist`

观察池用于跟踪你已经关注的股票。

观察池会显示加入日期、加入价、当前价和加入后涨跌幅。打开页面时系统会尝试刷新当前价格，方便判断“加入观察池之后涨了多少”。

状态说明：

| 状态 | 说明 |
|---|---|
| watching | 观察中 |
| triggered | 已触发买点 |
| waiting_pullback | 等待回踩 |
| weakening | 资金转弱 |
| stopped | 触发止损 |
| expired | 信号失效 |

建议：

- 不确定是否买入时先加入观察池。
- 盘中或第二天查看资金和建仓分变化。
- 如果资金转弱或触发止损，及时移出重点跟踪。

### 3.5 提醒页 `/alerts`

提醒页用于查看买点和风险提示。

提醒类型包括：

- 回踩到买入区间。
- 主力资金由负转正。
- 涨幅低于 3% 且资金净流入。
- 不破 MA10/MA20。
- RSI 不过热。
- 跌破止损位。
- 涨幅过大不追高。

可以点击页面按钮重新评估观察池中的股票。

### 3.6 复盘页 `/review`

复盘页用于验证历史推荐是否有效。

前提：

1. 已保存过每日推荐。
2. 推荐日后已经有 1/3/5 日后续 K 线。
3. 已运行复盘脚本：

```bash
python scripts/review_recommendations.py
```

页面包含：

- 1 日、3 日、5 日复盘表现。
- 开盘收益、最高收益、收盘收益、最大回撤。
- 是否触发买点和止损。
- 不同评分配置的历史胜率对比。

如何使用配置回测：

- 如果保守配置胜率明显更高，说明当前市场更适合低风险低吸。
- 如果激进配置表现更好，说明当前市场可能偏强势题材行情。
- 如果三套配置都不好，说明当前候选池质量或市场环境偏弱，应降低仓位或只观察。

### 3.7 设置页 `/settings`

设置页用于调整评分权重。

内置配置：

| 配置 | 适用场景 |
|---|---|
| 均衡配置 | 日常默认使用 |
| 保守配置 | 市场不稳定、想降低风险时 |
| 激进配置 | 题材强势、资金活跃时 |

操作：

1. 选择配置。
2. 调整权重。
3. 点击保存配置。
4. 如果要让扫描使用该配置，点击设为默认。

建议：

- 不确定时使用均衡配置。
- 连续复盘发现追高失败率高时，切换保守配置。
- 市场主线非常强时，可以尝试激进配置，但需要结合复盘结果。

## 4. LLM 分析使用

个股详情页可以触发 LLM 分析。

LLM 会看到：

- 当前价格和涨跌幅。
- 资金流入流出。
- 近 30 日资金流。
- 技术面评分。
- 消息面事件。
- 买点和风险条件。

适合让 LLM 辅助回答：

- 这只股票为什么入选。
- 当前更适合追、等回踩，还是放弃。
- 主要风险是什么。
- 需要观察哪些信号。

LLM 分析会保存到历史记录，方便后续复盘当时判断是否准确。

## 5. 数据保存和复盘

初始化数据库：

```bash
python scripts/init_discovery_db.py
```

保存推荐：

```bash
python scripts/save_daily_recommendations.py --sort-by tomorrow --limit 20
```

复盘推荐：

```bash
python scripts/review_recommendations.py
```

数据库文件：

```text
data/stock_discovery.db
```

不要随意删除数据库，否则推荐、观察池、复盘和 LLM 历史都会丢失。

## 6. 本地缓存

缓存目录：

```text
data/discovery_cache/
```

缓存作用：

- 减少重复拉取。
- 外部接口异常时提供兜底。
- 提升页面加载速度。

如果数据明显异常，可以删除对应缓存后重新拉取。

## 7. 常见问题

### 7.1 为什么没有今天的数据？

常见原因：

- 当天交易还没结束。
- 外部接口尚未更新。
- 接口临时失败或限流。
- 本地缓存还是旧数据。

处理方式：

```powershell
python scripts/update_discovery_cache.py --period 即时 --limit 100 --details 40
```

收盘后建议 15:30 或 16:00 后再重试。

### 7.2 为什么端口 8088 被占用？

说明已有服务在运行。查看并关闭：

Windows 11:

```powershell
netstat -ano | findstr :8088
taskkill /PID <PID> /F
```

Linux/macOS:

```bash
lsof -i :8088
kill <PID>
```

或换端口：

```powershell
python scripts/run_dashboard.py --port 8090
```

### 7.3 同事打不开页面？

检查：

- 启动时是否用了 `--host 0.0.0.0`。
- 同事访问的是否是局域网 IP，不是 `127.0.0.1`。
- 防火墙是否阻止端口。
- 电脑和同事是否在同一局域网。

### 7.4 LLM 分析失败？

检查：

- Mimo 或 OpenAI 环境变量是否正确。
- 当前网络是否能访问模型服务。
- 二级页是否有足够的股票数据。

### 7.5 复盘页为空？

常见原因：

- 没有保存过推荐。
- 推荐后还没有足够的交易日。
- 没有运行 `scripts/review_recommendations.py`。
- 外部 K 线接口失败。

## 8. 重要使用原则

- 不要只按一个股票的分数买入。
- 优先选择个股、板块、资金和消息面都一致的机会。
- 明显高开高走且涨幅过大时，不要只因为评分高就追。
- 复盘结果比单次预测更重要。
- ETF 或基金更看重板块长期适合度，个股短线分不能直接套用到基金。
- 保守配置适合弱市，激进配置适合强题材市场。
