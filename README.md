# 图片批量替换工具

一个简单的工具，用于遍历文件夹中的所有图片，使用图形化界面让用户选择一张图片，然后将其余图片替换为选中的图片（保持原文件名和尺寸不变）。

## 使用方法

### 方法1：直接运行（推荐）
```bash
python image_replacer.py
```
程序会自动弹出Windows文件夹选择对话框，让您选择包含图片的文件夹。

### 方法2：指定文件夹路径
```bash
python image_replacer.py C:\path\to\your\image\folder
```
直接在命令行中指定文件夹路径。

## 使用步骤

1. **运行脚本**：`python image_replacer.py`
2. **选择文件夹**：在弹出的Windows文件夹选择对话框中选择包含图片的文件夹
3. **搜索图片**：在搜索框中输入文件名关键词来过滤图片（可选）
4. **查看图片**：在图片选择界面中查看所有图片的缩略图
5. **选择图片**：点击"选择"按钮选择要作为模板的图片
6. **确认选择**：点击"确认选择"按钮，系统会显示确认对话框
7. **完成**：显示替换结果统计

## 注意事项

- ⚠️ **备份重要数据**：替换操作会覆盖原文件，请先备份重要图片
- 📸 **至少需要2张图片**：文件夹中至少需要2张图片才能进行替换操作
- 📏 **尺寸保持**：替换后保持目标图片的原始尺寸不变
- 🖼️ **格式保持**：替换后的图片会保持目标图片的原始格式
- ❌ **不可逆操作**：替换操作不可逆，请谨慎操作

## 🔧 故障排除

### PyInstaller路径问题
如果编译时出现 "No module named pyinstaller" 错误：

1. **检查PyInstaller安装位置**：
```bash
python -c "import PyInstaller; print(PyInstaller.__file__)"
```

2. **更新脚本中的路径**：
   - 打开 `one_click_build.py`
   - 修改第81行的 `pyinstaller_path` 变量为正确的路径

3. **手动编译**（仅供参考）：
```bash
# 使用完整路径
"E:\Scripts\pyinstaller.exe" --onefile --windowed --icon=icon.ico --name=image_replacer image_replacer.py
```
